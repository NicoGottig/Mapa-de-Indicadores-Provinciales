# Mapa de Indicadores Provinciales

Este proyecto incluye una aplicación desarrollada en Shiny que visualiza un mapa con indicadores productivos y de empleo a nivel provincial. Aunque la aplicación no está actualmente desplegada, el código fuente está disponible para revisión y uso.

## Características de la App

- **Visualización Interactiva**: La aplicación proporciona una visualización geoespacial interactiva de indicadores económicos y de empleo para diferentes provincias, permitiendo a los usuarios explorar y analizar datos de manera intuitiva.
- **Indicadores Productivos y de Empleo**: Se incluyen varios indicadores clave que ofrecen una visión general del desempeño productivo y del mercado laboral en distintas regiones.

## Cómo Acceder al Código Fuente

El código fuente de la aplicación se encuentra disponible en GitHub y puede ser descargado y ejecutado localmente utilizando R y Shiny.
